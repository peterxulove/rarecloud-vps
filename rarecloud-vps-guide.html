谁在运营

RareCloud 是罗马尼亚公司 RARE MOOD AGENCY SRL（Tax ID 45192771，VAT RO45192771）旗下的 VPS / 云品牌，背后就是持牌电信运营商 M247（AS9009）。NodeSeek 社区里也有人指出它「以前叫 VPSforVPN」——同一条 M247 网络，换了层皮做零售。

卖什么

四条产品线共 19 个可下单套餐：Linux KVM VPS（8 档）、Windows RDP VPS（3 档）、n8n 自动化 VPS（2 档）、OpenClaw AI 助手 VPS（2 档），外加 4 档 Web 虚拟主机与布加勒斯特的 Cloud VM。

最低价

€1.56/月（Micro KVM，768MB 内存，1TB 流量，一次付三年）。注意：Micro / Starter / Website Hosting 没有月付档，最低一次性付 1.5 年。

机房

12 个数据中心：11 个 VPS 机房（硅谷、凤凰城、达拉斯、纽约、伦敦、海牙、法兰克福、蒂米什瓦拉、康斯坦察、香港、东京）+ 1 个 Cloud VM 机房（布加勒斯特）。每个机房官网都给了 test IP，可以自己 ping / mtr 验证。

谁适合买

① 预算极低、能接受「年付当赌博」的人（年付 €9.75～€30 的活动款是它真正的价值所在）；② 大陆移动用户想要一台便宜的香港机；③ 想低成本跑 n8n / OpenClaw 这类预装应用的人。

谁不适合

① 需要放生产业务的人——2025–2026 社区里「宕机 / 失联 / 工单不回」的帖子密度很高；② 指望退款兜底的人——14 天退款写在条款里，实际执行极难，社区共识是「用 PayPal 付款，走 PayPal 争议」；③ 中国电信用户——香港 / 日本机房回程绕路，延迟高、丢包重。

★ 必须先知道

2026-09 起官方通知续费涨价；2025-12 荷兰节点强制迁移、退役多个 IP 段并更换全部 IP；充值赠金只有 60 天有效期且续费一次只能用掉一个周期。本文所有价格都是抓取时点快照，长期持有务必按「随时可能涨价、随时可能换 IP」来规划。

三、n8n 自动化 VPS —— 2 个档位 年付折合 €4.00/月

n8n VPS：预装好 n8n 与 HTTPS，开箱即用

n8n 是自建工作流自动化的热门开源工具，官方云版按执行次数收费。RareCloud 的做法是把 n8n、Nginx 反代、Let's Encrypt 证书、UFW 防火墙（只开 22/80/443）全部预装好，你只需要 SSH 进去跑一句 bash /root/setup-domain.sh yourdomain.com 绑定域名、拿证书。

★ 这条线的年付折扣是全站最猛的：Starter 月付 €9.50、年付总价 €48（折合 €4.00/月），Pro 月付 €19.50、年付 €68.25（折合 €5.69/月）。官方也直接写「无执行次数限制」——只要 CPU 和内存扛得住就跑多少。

  • Starter 用 SQLite 嵌入式数据库，适合小项目；Pro 是 Docker + PostgreSQL 16 + Redis 7 + 2 个 worker 节点的队列模式，数据库和缓存不对公网暴露。
  • 注意 n8n Starter（pid 36）与 OpenClaw Server（pid 49）价格完全一样，Pro 与 Desktop 同理——两条线在后台共用同一套计费配置。

⚠️ 购买前必读：6 条风险提示

RareCloud 的价格优势是真的，而社区对它稳定性和续费政策的质疑也是真的。下面 6 条是我认为下单前必须知道的，全部来自官方条款原文或 NodeSeek 原帖。

先充值还是先开机？——先开机，别囤赠金

充值赠金 60 天过期，且续费一次只能消耗一个周期。你手上的 VPS 越早开、周期排得越靠前，赠金越用得上；反过来先充值再慢慢开机，赠金大概率白瞎。

锁多久合适？——最稳的是 1 年，最多 2 年

年付比月付便宜 15%–17%，三年付再便宜一档；但 2026-09 已经涨过一轮、条款也没有长期锁价承诺。Plus / Pro / Win 系列两年付和三年付同价，锁三年纯属多担风险。

迁移风险要自己消化

历史已发生三次大规模迁移（荷兰→海牙、硅谷换 IP 段、老机换硬件）。TOS 明确「IP 是服务的一部分，不可携带、不可转让，商家改号会尽力避免中断」。所以 DNS 记录别写死，有条件就用 Cloudflare 之类的托管解析。

付款方式决定了你的退路

官方支持 PayPal、信用卡 / 借记卡、支付宝、加密货币、银行转账。社区的一致建议是优先用 PayPal——支付宝订单几乎没有成功退款的先例。

价格不含 VAT

官网价格全部是不含税价。欧盟客户若无有效 VAT ID，会被加收 19% 罗马尼亚增值税；中国大陆用户在结账前务必确认最终应付金额。

别把它当生产主力

99.9% uptime 的 SLA 是写在条款里的（低于阈值可按 downtime 的 10%/1% 申请退月费，需开工单），但 SLA 赔付和退款一样要看客服脸色。生产业务建议：年付一台 + 自己做快照 + 有兜底方案。

常见问题

RareCloud 是什么来头？靠谱吗？

运营方是罗马尼亚的 RARE MOOD AGENCY SRL（Tax ID 45192771，VAT RO45192771），背后是罗马尼亚持牌电信运营商 M247（AS9009），12 个机房里有 7 个直接挂在 M247 的 AS9009 下。它不是空壳新号，但确实是近两年在社区里争议很大的低价商家——「价格真香」和「随时可能跑路」两种评价同时存在。建议按年付玩具 / 副业机器的定位买。

最便宜多少钱？

€1.56/月——Micro KVM（1 vCPU / 768MB / 15GB NVMe / 1TB 流量），一次付三年 €56。注意 Micro 和 Starter 没有月付，最低一次性付 1.5 年。

可以按月付吗？

Linux KVM 里 Advanced / Core / DIY / Plus / Pro / Elite 和全部 Windows、n8n、OpenClaw 档位都可以月付；只有 Micro KVM、Starter KVM、Website Hosting 三档没有月付。Cloud VM 全部按小时计费、封顶月价。

中国大陆用户选哪个机房？

移动选香港（回程 CMI 直连，社区称「移动快乐鸡」）；电信 / 联通选德国（三网回程 4837 直连，延迟约 180–260ms）；电信不要选香港和东京，回程绕路、丢包明显。

怎么验证线路好不好？

每个机房官网页面都直接给了 test IP，例如法兰克福 85.121.52.2、伦敦 85.121.48.2、东京 85.121.50.2、香港 85.121.244.250。下单前先 ping 和 mtr 测一下再付钱。

支持支付宝吗？

支持。官方条款列出的支付方式是信用卡 / 借记卡、PayPal、支付宝、加密货币和银行转账。但社区一致提醒：想退款就用 PayPal 付，支付宝单几乎没成功退款的。

有备份吗？

没有。条款明确写了除非另有说明，RareCloud 不为客户数据做备份，硬件故障、误操作导致的数据丢失概不负责。Cloud VM 有快照服务（€0.05/GB/月，每台最多 5 个），KVM VPS 档位得自己解决备份。

退款政策是怎样的？

条款写的是 14 天退款（需满足「使用量极少」等条件），超出后按 as-is 处理，除非 30 天内换机或转余额。但社区反馈是：工单经常只回复「已上报高层」，有人退款拖了两个月，最后靠 PayPal 争议秒退。

IP 会被换掉吗？

会。历史上荷兰节点从原机房迁到海牙时整段 IP 全换（退役 45.129.13.0/24、45.148.11.0/24、45.142.192.0/24），硅谷节点也退役过多个 /24。条款明确 IP 不可迁移、不可转让。建议用第三方托管 DNS，别把解析挂在会变动的 IP 上。

能解锁流媒体吗？

基本别指望。有用户直接反馈「Gemini 定位飞到罗马尼亚，ChatGPT 直接判定为 VPN」，属于广播 IP。需要解锁请另找专门的 IP 商家。
