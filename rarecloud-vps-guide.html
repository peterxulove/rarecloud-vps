产品特点与注意事项

这是 RareCloud 的基本盘，也是全部 19 个套餐里选择最多的一条线。8 个档位从 768MB 内存的引流款一路排到 16GB 内存，所有档位都是真 KVM + NVMe。

价格结构要单独说清楚：月付最贵、三年付最便宜；但最便宜的两档（Micro / Starter）根本不提供月付，必须一次付 1.5 年起步。另外 Plus / Pro 两档两年付与三年付总价完全相同——也就是说锁三年并不会比锁两年更划算，这两档最多锁两年。

  • Micro KVM 的 768MB 内存是刻意做出来的引流款：能跑 WireGuard、静态页、轻量脚本，装完 Debian 后可用内存通常只剩 300MB 上下。别拿它跑 Docker 或数据库。
  • Advanced KVM（1C/2.5G/45G）是这条线唯一提供 /64 IPv6的档位，其余都是 /112 子网；想要完整 IPv6 子网就选它。
  • Do It Yourself 支持 vCPU 1→8、内存 1→32GB、硬盘 20→500GB、流量 1→20TB 全自选，但只有月付到年付四个周期，没有两年付与三年付。
  • 硬件按机房分化明显：德国机房给 Ryzen 7 3700X / 5800X（Geekbench 5 单核 982–1100），其他机房多为 Xeon E5-2683 v4 / E5-2690 v2（GB5 约 400–548）。买德国机等于顺带拿到更好的 CPU。

常见问题

RareCloud 是什么来头？

运营方是罗马尼亚的 RARE MOOD AGENCY SRL（Tax ID 45192771，VAT RO45192771，Reg. No. J13/3713/2021），背后是罗马尼亚持牌电信运营商 M247（AS9009），12 个数据中心里有 7 个直接挂在 M247 的 AS9009 下。它不是空壳新号，但确实是近两年在社区里争议很大的低价商家——「价格真香」和「随时可能跑路」两种评价同时存在。建议按年付玩具 / 副业机器的定位买。

最便宜多少钱？真能买到吗？

€1.56/月——Micro KVM（1 vCPU / 768MB / 15GB NVMe / 1TB 流量），一次付三年 €56。注意 Micro 和 Starter 没有月付，最低一次性付 1.5 年；768MB 内存装完系统基本就满了。

可以按月付吗？

Linux KVM 里的 Advanced / Core / DIY / Plus / Pro / Elite 与全部 Windows、n8n、OpenClaw 档位都可以月付；只有 Micro KVM、Starter KVM、Website Hosting 三档没有月付。Cloud VM 全部按小时计费、封顶月价。

哪些套餐锁长周期不划算？

Plus VPS、Pro VPS、Win 4G / 8G / 12G 的两年付与三年付总价完全相同，锁三年没有任何额外折扣，这几档最多锁两年。Enterprise 虚拟主机也有类似异常（两年付 / 三年付与 Business 同价），买前建议开工单确认。

中国大陆用户选哪个机房？

移动选香港（回程 CMI 直连，社区称「移动快乐鸡」）；电信 / 联通选德国（法兰克福 / 蒂米什瓦拉，回程联通 4837 直连，延迟约 180–260ms）；电信不要选香港和东京，回程绕路、丢包明显。美国四城只适合纯海外业务。

怎么验证线路好不好？

每个数据中心页面都直接给了 test IP，例如法兰克福 85.121.52.2、伦敦 85.121.48.2、海牙 85.121.54.2、东京 85.121.50.2、香港 85.121.244.250。下单前先 ping 和 mtr 测一遍再付钱。

支持支付宝吗？

支持。官方条款列出的支付方式是信用卡 / 借记卡、PayPal、支付宝、加密货币和银行转账。但社区一致提醒：想退款就用 PayPal 付，支付宝单几乎没成功退款的。

有备份吗？

没有。条款明确写了除非另有说明，RareCloud 不为客户数据做备份，硬件故障、误操作导致的数据丢失概不负责。Cloud VM 有快照服务（€0.05/GB/月，每台最多 5 个），KVM VPS 档位得自己解决备份。

退款政策是怎样的？

条款写的是 14 天退款（需满足「使用量极少」等条件），超出后按 as-is 处理，除非 30 天内换机或转余额。但社区反馈是：工单经常只回复「已上报高层」，有人退款拖了两个月，最后靠 PayPal 争议秒退。

IP 会被换掉吗？

会。历史上荷兰节点从原机房迁到海牙时整段 IP 全换（退役 45.129.13.0/24、45.148.11.0/24、45.142.192.0/24），硅谷节点也退役过多个 /24。条款明确 IP 不可迁移、不可转让。建议用第三方托管 DNS，别把解析挂在会变动的 IP 上。

能解锁流媒体 / 用 ChatGPT 吗？

IP 基本是广播段。有用户直接反馈「Gemini 定位飞到罗马尼亚，ChatGPT 直接判定为 VPN」。如果你的用途依赖干净的住宅 / 机房 IP，请另找专门商家。

Micro KVM 的 768MB 内存能干什么？

够跑 WireGuard、反向代理、静态站、轻量脚本和监控 agent。不够跑 Docker（哪怕一个容器）、数据库、Java 项目或任何带编译的工具链。装完 Debian 后可用内存通常只剩 300MB 上下。如果只是想要「一台便宜的常在线机器」，它很合适；想跑服务请至少上 Core VPS（2GB）。

Cloud VM 和 KVM VPS 有什么区别？该选哪个？

KVM VPS 是预付固定周期（月付到三年付），11 个机房任选，适合长期持有；Cloud VM 是按小时后付费、月价封顶，只在布加勒斯特，但支持随时改配置而不换 IP、自带云防火墙与私网，适合弹性负载和短期测试。

选购注意事项与风险提示

下单前务必确认这几点。这些不是「劝退」，而是让你用对预期——RareCloud 的低价是真的，它的不确定性也是真的，两件事同时成立。
  • 先开机，别囤赠金。充值赠金只有 60 天有效期，且「续费时最多且只能续一个周期」。手上的 VPS 越早开、周期排得越靠前，赠金越用得上；反过来先充值再慢慢开机，赠金大概率白瞎。
  • 锁多久合适：默认 1 年，最多 2 年。年付比月付便宜 15%–17%，三年付再便宜一档；但 2026-09 已经涨过一轮，条款也没有长期锁价承诺。Plus / Pro / Win 系列的两年付与三年付同价，锁三年纯属多担风险。
  • 迁移风险要自己消化。历史上已发生多轮大规模迁移（荷兰 → 海牙、硅谷退役 IP 段、老机换硬件）。条款明确「IP 是服务的一部分，不可携带、不可转让，商家改号会尽力避免中断」。DNS 记录别写死 IP，有条件就用 Cloudflare 之类的托管解析。
  • 付款方式决定了你的退路。官方支持信用卡 / 借据卡、PayPal、支付宝、加密货币、银行转账。社区的一致建议是优先用 PayPal——支付宝订单几乎没有成功退款的先例。
  • 价格不含 VAT。官网价格全部是不含税价。欧盟客户若无有效 VAT ID，会被加收 19% 罗马尼亚增值税；中国大陆用户在结账前务必确认最终应付金额。
  • 别把它当生产主力。99.9% uptime 的 SLA 写在条款里（低于阈值可按 downtime 的 10%/1% 申请退月费，需开工单），但 SLA 赔付和退款一样要看客服脸色。生产业务建议年付一台 + 自己做快照 + 准备兜底方案。
  • 商家已发过「涨价预告 + 给半月原价窗口」的邮件。有用户按 2026-06 的邮件在涨价前续了费，随后续费价仍然上调；另有用户在赠金还没用完时就续了两次，结果赠金彻底花不出去。不要把促销邮件当成锁价承诺。
  • 14 天退款不是兜底。条款写的是 14 天（需满足「使用量极少」等条件），超出后按 as-is 处理。但社区执行情况是：工单经常只回「已上报高层」，有人拖了两个月，最后靠 PayPal 争议秒退。

如果这些风险你都不能接受，建议看同价位更稳的商家；如果能接受，那 RareCloud 的性价比确实是第一梯队的。
